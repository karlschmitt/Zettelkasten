# SkiaSharp

_SkiaSharp is an open-source, cross-platform 2D graphics library for .NET developers that is powered by Google's native [Skia](https://skia.org/) graphics engine_.

It acts as a high-performance C# wrapper that translates standard managed drawing commands into hardware-accelerated instructions. This allows developers to render sharp vector shapes, bitmaps, text, and rich visual effects with pixel-perfect consistency across multiple operating systems and form factors.

## Key Features and Capabilities

* Cross-Platform Support: Write drawing code once and deploy seamlessly across Windows, macOS, Linux, iOS, Android, and WebAssembly (WASM).
* GPU & CPU Acceleration: Delivers smooth, high-performance visual rendering by leveraging native GPU acceleration through modern graphics context bindings.
* Rich Drawing API: Provides comprehensive control over paths, gradients, shaders, blend modes, image filters, and text layout.
* Ecosystem Integration: Serves as the underlying graphics and rendering backbone for major .NET UI frameworks like [.NET MAUI](https://github.com/dotnet/maui), [Uno Platform](https://platform.uno/), and [Avalonia](https://avaloniaui.net/).

## Supported Platforms & Environments

| Target Category      | Supported Environments / Frameworks                                       |
| -------------------- | ------------------------------------------------------------------------- |
| Desktop              | Windows (WPF, WinForms, WinUI 3), macOS, Linux                            |
| Mobile               | Android, iOS, tvOS, Mac Catalyst, Tizen                                   |
| Web & Cross-Platform | WebAssembly (WASM), .NET MAUI, Uno Platform \[.NET 6+, .NET Standard 2.0] |
