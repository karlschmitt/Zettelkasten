# Electron.js for absolut beginners

**Electron** allows you to build cross-platform desktop apps for Windows, macOS, and Linux using HTML, CSS, and TypeScript.

## 1. How Electron Architecture Works

Electron apps run on two distinct processes:

1. **Main Process (`main.ts`)**: Runs in full Node.js. Controls the app's lifecycle, creates native windows, and handles system resources (files, menus, tray icons).

2. **Renderer Process (`renderer.ts`)**: Runs the user interface inside Chromium (like a web page).

3. **Preload Script (`preload.ts`)**: The secure bridge between Main and Renderer processes using IPC (Inter-Process Communication).


## 2. Project Setup

The easiest way to set up a production-ready Electron project with TypeScript is using **Electron Forge**:



Bash

```
npx create-electron-app@latest my-electron-app --template=vite-typescript
cd my-electron-app
npm start
```

This creates a pre-configured Vite + TypeScript template.



## 3. Core Files Explanation

### A. The Main Process (`src/main.ts`)

This script initializes Node.js and manages your application windows.



TypeScript

```
import { app, BrowserWindow, ipcMain } from "electron";
import path from "path";

// Declare path constants generated by the build tool
declare const MAIN_WINDOW_VITE_DEV_SERVER_URL: string;
declare const MAIN_WINDOW_VITE_NAME: string;

function createWindow(): void {
  const mainWindow = new BrowserWindow({
    width: 900,
    height: 600,
    webPreferences: {
      // Points to our secure bridge script
      preload: path.join(__dirname, "preload.js"),
      // Security defaults: block renderer from Node.js direct access
      nodeIntegration: false,
      contextIsolation: true,
    },
  });

  // Load dev server or built file
  if (MAIN_WINDOW_VITE_DEV_SERVER_URL) {
    mainWindow.loadURL(MAIN_WINDOW_VITE_DEV_SERVER_URL);
  } else {
    mainWindow.loadFile(
      path.join(__dirname, `../renderer/${MAIN_WINDOW_VITE_NAME}/index.html`)
    );
  }
}

// IPC Listener: Receive message from UI, perform system action, send back response
ipcMain.handle("ping-system", async () => {
  return `Pong! Node version running in main process: ${process.versions.node}`;
});

app.whenReady().then(createWindow);

// Quit when all windows are closed (except on macOS)
app.on("window-all-closed", () => {
  if (process.platform !== "darwin") {
    app.quit();
  }
});
```

### B. The Secure Preload Bridge (`src/preload.ts`)

The `contextBridge` safely exposes limited backend capabilities to the renderer window without giving the UI full access to Node.js.



TypeScript

```
import { contextBridge, ipcRenderer } from "electron";

// Define the API exposed to window.electronAPI
contextBridge.exposeInMainWorld("electronAPI", {
  pingSystem: (): Promise<string> => ipcRenderer.invoke("ping-system"),
});
```

To give TypeScript auto-complete in your UI code, declare the type globally:



TypeScript

```
// Create a declaration file or put at bottom of src/preload.ts
export interface IElectronAPI {
  pingSystem: () => Promise<string>;
}

declare global {
  interface Window {
    electronAPI: IElectronAPI;
  }
}
```

### C. The Renderer Process (`src/renderer.ts`)

This acts as your front-end web application logic.



TypeScript

```
// Add logic for button click
document.addEventListener("DOMContentLoaded", () => {
  const btn = document.getElementById("ping-btn");
  const output = document.getElementById("output");

  if (btn && output) {
    btn.addEventListener("click", async () => {
      // Call the safe function exposed via preload script
      const response = await window.electronAPI.pingSystem();
      output.innerText = response;
    });
  }
});
```

HTML

```
<!DOCTYPE html>

  </head>
  <body>
    <h1>Electron + TypeScript</h1>
    <button id="ping-btn">Ping Main Process</button>
    <p id="output">Click the button to test IPC communication...</p>

    <script type="module" src="/src/renderer.ts"></script>
  </body>
</html>
```

## 4. Running and Building

* **Start in Development mode:**



  Bash

  ```
  npm start
  ```

* **Build an Executable installer (.exe / .dmg / .deb):**



  Bash

  ```
  npm run make
  ```

  This creates bundled native installers inside the `out/` folder.
