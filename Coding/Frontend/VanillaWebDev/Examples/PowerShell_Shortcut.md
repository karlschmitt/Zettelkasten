# PowerShell Shortcut

You can open PowerShell instantly using the built-in keyboard shortcut `Win + X` followed by `I` (or `A` for an administrator prompt).

## Built-In Keyboard Shortcuts

* `Win + X` then `I`: Opens a standard PowerShell or Terminal window.
* `Win + X` then `A`: Opens an elevated (Administrator) PowerShell or Terminal window.
* `Win + R`, type `powershell`, then press `Ctrl + Shift + Enter`: Quickly launches PowerShell as an administrator from the Run dialog.

## Creating a Custom Desktop Shortcut with a Hotkey

If you want to assign your own custom keyboard combination (such as `Ctrl + Alt + T`): \[1]

1. Right-click an empty space on your desktop, select New, and click Shortcut.
2. Type `powershell` in the location box and click Next.
3. Give your shortcut a name (e.g., `PowerShell`) and click Finish.
4. Right-click the newly created desktop shortcut and select Properties.
5. Click inside the Shortcut key field and press the key combination you want to use (like `Ctrl + Alt + P`).
6. (Optional) If you always want it to open with full privileges, click the Advanced button on the Shortcut tab and check Run as administrator.
7. Click Apply and then OK to save your changes. \[1, 3, 4, 5, 6]
